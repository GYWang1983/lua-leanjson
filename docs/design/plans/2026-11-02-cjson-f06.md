# F06 external-array encoding implementation plan

> For agentic workers: use subagent-driven-development for one coupled task; parent supervises independent review and local-main integration.

**Goal:** implement external array-like table encoding from the existing F06 spec against pinned OpenResty lua-cjson.

**Architecture:** extend the shared table classifier so a real `__len` metamethod selects a virtual array and its values use normal indexed access. Preserve array-marker precedence and source-backed proxy paths. The ordinary encoder and existing reader/assignment/fork snapshots consume the same classification; source origins must not bypass virtual reads. Keep iterative traversal, reader snapshots and resource ownership intact.

**Tech stack:** LuaJIT/OpenResty Lua, existing Rust source backend, pinned C oracle.

**Spec:** `docs/design/cjson-compatibility-fixes.md` F06, `vendor/lua-cjson` commit 617164a0fe3bb647128178f9caefb304b8573bb6, `agentzh.t:TEST23`.

## Global Constraints

- Use the pinned compiled reference explicitly via package.loadlib; do not fall back to the image cjson. Parent reference and native probe are in this plan workspace. No upstream expected-output or adapter changes, runtime cjson fallback, unrelated fixes or broad formatting.
- Match native recognition: array_mt has precedence and uses raw length/values; otherwise raw real-metatable __len (including protected metatables and callable values) selects an array, ignores hash keys and bypasses raw-key sparse classification. No inherited/fabricated __len via metatable __index. __index is honored for normal virtual element reads; ordinary tables without __len retain current behavior.
- Native Lua number/string conversion, fractional truncation, nonnumeric/nil/boolean/table/cdata results ->0 and finite negative length ->empty array are supported. Probe edge string coercions rather than guess. Do not reproduce undefined/nonportable C double-to-int conversion: nonfinite or truncated out-of-signed32-range lengths fail controllably with a documented LeanJSON error. No arbitrary smaller length cap.
- Normal/safe/new, compact/indent, skip-unsupported, null/hole, nested/cross-codec values, marker/empty-table/sparse settings, cycles/depth/errors remain correct. Preserve callback errors (including non-string errors) and native non-callable method errors where deterministic. Reader errors keep existing nil/error and no-partial-output behavior.
- Reader/snapshot captures external callback results at construction, not again in length/next; encode must not invoke length twice through keep_origin matching or reuse stale origin spans when virtual semantics override table contents. JSON-backed own proxies never route through external metamethod classification. Plain encode stays iterative and does not snapshot the entire ordinary input.
- Retain bounded source strings/output and no-GC cleanup. Investigate ephemeral file/feed proxy children returned by __index: source lifetime must survive later callbacks/GC and snapshot-to-lease transfer; failed or cancelled construction/traversal must not retain acquired resources. Change shared lease/snapshot plumbing only for a demonstrated F06 risk and cover it.
- Work in the existing linked worktree. Implementer/reviewer do not commit, switch branches, push or spawn subagents. Parent stages only task files and commits/fast-forwards local main after verification; no push requested. Preserve previous local-main commits, ignored sibling plan directories and unrelated work.

## Review Focus

- Metatable marker precedence, protected metatables, non-callable/callable __len and inherited fake metamethods.
- Invalid/coerced/fractional/negative/huge lengths without uncontrolled loops or unsafe C integer conversion.
- Virtual hash keys, missing indexes, unsupported values, callback errors, cycles and depth.
- keep_origin/raw source bypass, nested external arrays, repeated callbacks and reader settings/input snapshots.
- Ephemeral source children, GC/yield/error/cancellation while constructing snapshots, leases and descriptors.
