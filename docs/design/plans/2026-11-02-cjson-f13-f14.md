# F13/F14 encoding implementation plan

> For agentic workers: use subagent-driven-development for the coupled task below; parent supervises review, verification and local-main integration.

**Goal:** implement `encode_indent` and `encode_skip_unsupported_value_types` against pinned OpenResty lua-cjson without losing bounded lazy/file/feed encoding.

**Architecture:** independent codec settings drive the iterative ordinary-table encoder and the bounded reader. Indentation forces container traversal (never full document materialization); raw scalar spans remain eligible. Reader format policy is captured at creation. Skip policy is evaluated before punctuation; unsupported roots produce an empty string, unsupported object members are omitted and arrays compact according to the oracle. Preserve key validation and all other encoding errors.

**Tech stack:** LuaJIT/OpenResty Lua, existing Rust source backend, pinned native cjson oracle.

**Spec:** `docs/design/cjson-compatibility-fixes.md` F13/F14; pinned `vendor/lua-cjson` commit 617164a0fe3bb647128178f9caefb304b8573bb6.

## Global Constraints

- Implement native defaults, getter/setter values and argument errors with independent module/new/safe settings and failure atomicity. Numeric/non-whitespace/NUL indentation behavior is determined by the pinned oracle, not guessed; keep its accepted non-whitespace indentation.
- Both ordinary-table and proxy/reader output honor the calling codec. Indentation applies consistently to clean raw containers, dirty nodes, keep_origin and nested proxy/table combinations; raw scalar spellings may stay original as documented. Empty versus all-skipped containers follow native formatting.
- Skip applies only to unsupported value types; nil/null, supported numeric cdata, sparse-array policy, invalid object keys, invalid numbers, cycles and depth errors preserve existing behavior. Do not extend F06 external arrays or F18 mutation semantics.
- No full materialization or runtime cjson fallback. Bounded source reads and output chunks, accurate reader:length(), cancellation and release without forced GC. Use explicit stacks, including deep indentation generation; no output-sized indentation temporary in reader.
- Do not alter upstream expectations/adapters to make cases pass. Keep remaining failures and previous RSS boundary visible. No whole-project formatting or unrelated refactors.
- Work only in existing linked worktree. Implementer/reviewer must not commit, switch branches, push, or spawn subagents. Parent commits to local main only after gates; push is not requested.

## Review Focus

- All-skipped arrays/objects, holes, mixed unsupported types and invalid keys with unsupported values.
- Raw container and keep_origin bypass of indent; non-whitespace/embedded NUL indent and numeric coercion.
- Reader snapshots across settings changes/cross-codec calls, length consistency and one-byte chunk boundaries.
- Deep nesting, huge scalar strings and file/feed cleanup under error or cancellation.
- Sparse/invalid-number/cycle errors must not be silently swallowed by skip; no mutation of input during encoding.
